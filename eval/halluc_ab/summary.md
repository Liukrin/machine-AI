## 4. 结论（数字均来自本次运行）

1. **无引用句占比**：A 1.000 → B 0.732 → C 0.063（Δ(B−A) -0.268；Δ(C−A) -0.937）。B 组残值说明：线上提示词只要求「答案末尾标注」而非逐句标注，与本指标「句内或句尾含标记」的口径天然不匹配，不能读成「大部分句子无依据」；C 组即该口径错配的对照变体。
2. **逐句标注的净效应（C−B）**：无引用句占比 0.732 → 0.063（Δ -0.668）；实质句数 149 → 126（句数变化本身会影响 micro 占比，需与 details.csv 逐题明细同读）。
3. **拒答率（控制变量）**：A 0.083（闸 2+自述 1） / B 0.083（闸 2+自述 1） / C 0.056（闸 2+自述 0） → B 与 A 持平，引用率改善不来自「少答」；C 比 A 低 2.8 个百分点，改善不是靠少答换来的。
4. **虚构文档检出条数**：A 抽取 0 标识、检出 0 条 / B 抽取 62 标识、检出 0 条 / C 抽取 64 标识、检出 0 条。口径为「来源标识（chunk_id）∉ 该题检索候选集合」；完全不打引用的组检出天然为 0，属分母效应，不能直接读成「该组不虚构」。

## 6. 残留局限

- 36 题、temperature=0 的单次采样，无重复采样与显著性检验，差值只作方向性结论。
- 虚构文档口径为 chunk_id 集合比对，未纳入文件名/书名等非结构化来源标识，bigram 句级校验仅作旁证列出。
- 「答案末尾标注」与逐句口径的错配影响已由 C 组对照量化（见第 4 节）；但 C 组提示词未上线，线上是否改条款需另行评审。
- 无引用句占比按句池（micro）合并计算，长答案句数多的题权重更大；逐题明细见 details.csv，可按需改macro。
- 各组共用拒答闸，提示词无法影响闸内拒答，故各组的闸拒答必然相同。
