### 4.1 重复编码冗余（已知问题量化，不改代码）

- 单次 model.encode(单句) 中位数：**5.0 ms**（30 次实测）
- 生产路径每题 encode 3 次：retrieve 内 1 次、vector_top1_distance 1 次、_chunk_distances 1 次
- 理论可节省（缓存复用后少 2 次）：**10.0 ms/题**，占 t_total 均值 **0.4%**

## 5. 结论（数字均来自本次运行）

1. **LLM 生成是端到端主要耗时**：t_generate 均值 2702 ms，占 t_total 均值（2724 ms）的 99.2%；首 token 延迟 P50 1666 ms。
2. **本地计算开销很小**：检索 + 逐块距离 + 拒答闸合计均值 22 ms，仅占 0.8%；其中重复编码 3 次理论可省 10.0 ms（0.4%）。
3. **Token 以 input 为主**：总体 input 均值 1193 vs output 均值 94；table 题 input 均值 2258 vs text 题 917，表格题上下文更长。
